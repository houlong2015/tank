## 🎯 项目简介

这是经典 FC 游戏「坦克大战」的网页版复刻，使用纯 HTML5 Canvas 实现，无需任何游戏引擎。项目由 TRAE SOLO AI 辅助开发，从零到完成仅用时 10 分钟。

## ✨ 游戏特性

| 功能 | 说明 |
|------|------|
| 🎯 **核心玩法** | WASD 移动 + 空格发射，经典操作体验 |
| 🤖 **敌人 AI** | 自动移动、追踪玩家、智能射击 |
| 🗺️ **地图系统** | 砖墙（可破坏）、钢墙（不可破坏）、水域（阻挡） |
| 📊 **关卡系统** | 难度递增，敌人数量和速度逐关提升 |
| 💥 **爆炸特效** | 炫酷的粒子爆炸动画 |
| 📱 **移动适配** | 虚拟方向键 + 发射按钮，支持触屏操作 |
| 🎨 **精美 UI** | 现代化游戏界面，分数/生命/关卡实时显示 |

## 🕹️ 如何游玩

### 在线体验

1. 克隆仓库
```bash
git clone https://github.com/houlong2015/tank.git
cd tank
```

2. 启动本地服务器
```bash
python3 -m http.server 8080
```

3. 打开浏览器访问 http://localhost:8080

### 控制方式

#### 💻 PC 端
| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格` | 发射子弹 |
| `P` | 暂停/继续 |

#### 📱 移动端
- 左下角虚拟方向键控制移动
- 右下角红色按钮发射子弹

## 🎮 游戏规则

1. **目标**：消灭所有敌方坦克，保护基地
2. **生命**：初始 3 条命，被击中后重生
3. **基地**：地图底部中央的金色三角形是你的基地，不能被摧毁
4. **过关**：消灭当前关卡所有敌人后进入下一关
5. **失败**：生命耗尽或基地被摧毁则游戏结束

## 🗺️ 地图元素

| 元素 | 外观 | 特性 |
|------|------|------|
| 砖墙 | 🟫 棕色方块 | 可被子弹摧毁 |
| 钢墙 | ⬜ 灰色金属 | 无法被摧毁 |
| 水域 | 🔵 蓝色波纹 | 坦克无法通过 |
| 基地 | 🔺 金色三角 | 需要保护，被击中则游戏结束 |

## 🛠️ 技术实现

- **渲染引擎**：HTML5 Canvas 2D
- **游戏循环**：requestAnimationFrame 60fps
- **碰撞检测**：AABB 矩形碰撞
- **状态管理**：纯 JavaScript 对象
- **响应式设计**：CSS Media Queries
